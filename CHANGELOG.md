# Changelog

## 1.0.0 — 2026-11-02

- Added the missing launcher `MainActivity` and native navigation UI.
- Added project list/create/rename/delete flows, editor, file creation/save/delete and syntax coloring.
- Added Android Java, Web, Python, C++/CMake and Flutter starter templates.
- Added safe ZIP import/export via Android's document picker.
- Added encrypted API-token storage backed by Android Keystore.
- Added GitHub repository listing/creation, repository archive import, upload, Actions dispatch/history and artifact ZIP download.
- Added AI API clients for OpenAI-compatible services, Gemini and Claude, with explicit source-code consent.
- Added optional VirusTotal APK upload and SHA-256 report.
- Added theme selection, 16 locale options and RTL behavior for Arabic/Urdu/Persian.
- Pinned build settings to AGP 8.9.2, Gradle 8.11.1, JDK 17 and Android SDK 35.

This changelog describes source features. It does not claim that this environment generated or device-tested an APK.
