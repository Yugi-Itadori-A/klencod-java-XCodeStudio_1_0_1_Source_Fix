# XCode Studio 1.0.0 — حزمة مصدر أندرويد

هذه حزمة مشروع Android مكتوب بـ Java، وبها نقطة تشغيل حقيقية باسم `MainActivity` وواجهة تنقّل فعلية. الحزمة مخصّصة لفتحها في Android Studio أو بنائها من خلال GitHub Actions.

## أهم ما يعمل في المصدر

- واجهة رئيسية بأقسام المشاريع والمحرر وGitHub ومساعد AI والفحص الأمني والإضافات والإعدادات.
- إنشاء مشاريع من قوالب فارغة وAndroid Java وWeb وPython وC++/CMake وFlutter.
- عرض المشاريع المحلية وإعادة تسميتها وحذفها.
- إنشاء الملفات وفتحها وتعديلها وحفظها، مع تلوين رموز أساسي.
- استيراد ZIP وتصديره من خلال مدير ملفات أندرويد، مع حدود لحجم الأرشيف وعدد ملفاته ومنع مسارات الاستخراج الخبيثة.
- ربط GitHub باستخدام Personal Access Token، وعرض المستودعات وإنشاؤها واستيراد مشروع ZIP ورفع الملفات وتشغيل GitHub Actions ومتابعة عمليات البناء وتنزيل Artifact ZIP.
- الاتصال بمزوّدي OpenAI وGemini وClaude ومزوّدات متوافقة مع واجهة OpenAI. مفاتيح API تحفظ مشفرة، ولا يرفق محتوى الملف المفتوح إلا بعد تحديد الموافقة.
- فحص APK اختياري عبر VirusTotal بعد تأكيد منفصل قبل رفع الملف.
- إدارة بيانات الإضافات دون تشغيل كودها.
- اختيار 16 لغة للواجهة واتجاه RTL للعربية والأردية والفارسية. تسميات التنقل مترجمة، لكن بعض النصوص داخل الشاشات لا تزال بالعربية.

## طريقة البناء

المتطلبات: JDK 17، وAndroid SDK Platform 35، وBuild Tools 35.0.0. يحتوي المشروع على سكربت `gradlew` ينزّل Gradle 8.11.1 عند أول تشغيل، ولذلك يحتاج إلى اتصال بالإنترنت وأدوات `curl` أو `wget` و`unzip`.

من مجلد المشروع نفّذ:

```bash
sh ./gradlew :app:assembleDebug
```

ستجد APK التجريبي هنا:

```text
app/build/outputs/apk/debug/app-debug.apk
```

أو ارفع المشروع إلى GitHub، ثم افتح Actions واختر **Android build** وشغّل Workflow. بعد نجاح المهمة نزّل Artifact باسم `XCodeStudio-debug-apk`.

## حدود يجب معرفتها قبل البناء

هذا الإصدار ليس IDE متكاملًا بمستوى Android Studio أو VS Code. المحرر نصّي مع تلوين بسيط، ولا يحتوي حتى الآن على LSP أو إكمال برمجي احترافي أو Debugger أو Terminal أو Refactoring أو محاكي. كذلك لا يبني كل لغات البرمجة محليًا؛ سير العمل المرفق يبني تطبيق XCode Studio نفسه، أما بناء مشاريع المستخدم فيحتاج إعداد Workflow مناسبًا لنوع المشروع.

شاشة الإضافات تسجل البيانات الوصفية فقط ولا تشغّل الإضافات. اختيار اللغة يبدّل اتجاه الشاشة وتسميات التنقل الأساسية، وليس ترجمة كاملة لكل حوار ونص. GitHub وAI وVirusTotal تحتاج مفاتيح صحيحة وصلاحيات واتصال إنترنت وحصص استخدام من المزوّدين.

لم أتمكن من استخراج APK في بيئة الإنشاء التي أُعدّت فيها هذه الحزمة، لأن Android SDK غير مثبت والاتصال بمستودعات تنزيل Gradle غير متاح. لذلك هذه حزمة مصدر، ولم يتم الادعاء أن APK بُني أو اختُبر على هاتف فعلي. استخدم خطوات البناء أعلاه لإنتاج APK والتحقق من تشغيله على جهازك.
