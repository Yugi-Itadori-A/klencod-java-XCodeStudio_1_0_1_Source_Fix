# دليل XCode Studio — التشغيل والبناء

## فتح المشروع في Android Studio

1. فك ضغط حزمة XCode Studio كاملة.
2. افتح المجلد الذي يحتوي على `settings.gradle` في Android Studio، وليس مجلد `app` وحده.
3. استخدم JDK 17، وثبّت Android SDK Platform 35 وBuild Tools 35.0.0.
4. اترك Gradle ينفّذ المزامنة. يحتاج أول تشغيل إلى اتصال بالإنترنت لتنزيل Gradle وإضافات البناء.
5. من قائمة Build اختر إنشاء APK. ملف Debug الناتج سيكون داخل:
   `app/build/outputs/apk/debug/app-debug.apk`

## البناء عبر GitHub Actions

1. أنشئ مستودعًا في حساب GitHub وارفع إليه محتويات هذا المشروع.
2. افتح تبويب Actions.
3. اختر Android build ثم Run workflow.
4. بعد اكتمال المهمة، افتح نتيجة التشغيل ونزّل Artifact باسم `XCodeStudio-debug-apk`.

المستودع يحتاج تفعيل GitHub Actions. لا يقوم التطبيق بنشر APK على Google Play.

## ربط GitHub من التطبيق

استخدم Personal Access Token بصلاحيات مناسبة للمستودعات وGitHub Actions. يحتاج رفع الملفات إلى صلاحية Contents للقراءة والكتابة، واستيراد المستودعات إلى Contents للقراءة، وتشغيل ومتابعة Actions إلى Actions للقراءة والكتابة بحسب العملية. لا ترسل الرمز إلى أي شخص، ولا تضعه في ملف داخل المشروع.

## ربط الذكاء الاصطناعي

اختر المزوّد، وأدخل اسم النموذج الصحيح المتاح لحسابك ومفتاح API. يمكن حفظ المفتاح مشفرًا على الجهاز. لا يرسل التطبيق محتوى ملف المحرر إلى المزوّد إلا عند تفعيل مربع الموافقة على إرفاق الكود.

## الفحص الأمني

فحص VirusTotal اختياري. قبل الرفع يعرض التطبيق تأكيدًا لأن ملف APK سيُرسل إلى طرف خارجي. نتيجة لا تظهر اكتشافات لا تعني ضمان سلامة الملف بشكل مطلق.

## حدود هذا الإصدار

هذا إصدار مصدر عملي يفتح واجهة Android فعلية ويشغّل وظائف إدارة المشاريع الأساسية والاتصالات المحددة. لكنه ليس بعد IDE بمستوى Android Studio أو VS Code: لا يتضمن LSP أو إكمالًا ذكيًا محليًا أو Debugger أو Terminal مدمجًا أو بناءً محليًا عامًا لكل اللغات. شاشة الإضافات تسجل البيانات الوصفية فقط ولا تنفذ الإضافات. اختيار واحدة من 16 لغة يبدّل اتجاه الواجهة وتسميات التنقل الأساسية، لكن جميع النصوص داخل الشاشات لم تُترجم كاملة بعد.

لم يُنتج APK جاهزًا من بيئة الإنشاء الحالية؛ Android SDK غير موجود هنا، وبيئة التنزيل لا تستطيع الوصول إلى مستودعات Gradle. لذلك يجب إجراء أول بناء من Android Studio أو GitHub Actions كما في الخطوات أعلاه. لم يتم تأكيد تشغيل التطبيق على جهاز فعلي في هذا العمل.
